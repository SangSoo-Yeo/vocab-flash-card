## 수정 기록

### 수정 기록 1
- 발견한 문제: 편집 화면에서 카드 순서를 바꿀 수 없었다. 카드는 추가한 순서로만 보이고, 영단어나 뜻 기준으로 훑어보거나 순서를 직접 고칠 방법이 없었다.
- AI에게 전달한 요청: 편집 화면에 카드 정렬 기능을 추가해주세요. 번호 옆에 끌기 손잡이를 두어 마우스와 터치로 카드를 끌어서 저장 순서를 바꿀 수 있게 하고, 표 위의 정렬 드롭다운에서 저장된 순서, 영단어 A-Z, 영단어 Z-A, 뜻 가나다순, 뜻 가나다 역순, 상태별(틀림, 미학습, 맞춤 순)을 고를 수 있게 해주세요. 자동 정렬은 화면 표시만 바꾸고 학습의 "원래 순서"와 CSV 내보내기에는 영향을 주지 않으며, 자동 정렬 중에는 끌기를 비활성화해주세요.
- 수정 후 테스트 결과: 의도한 대로 작동했다. 끌어서 저장 순서를 바꿀 수 있고, 정렬 드롭다운의 항목이 각 기준대로 표시되며, 자동 정렬 중에는 끌기가 비활성화되었다.
- 수정 이유: 카드가 많아지면 추가한 순서만으로는 원하는 단어를 찾거나 배치하기 어렵다. 저장 순서를 바꾸는 수동 정렬과, 저장 순서를 건드리지 않고 보기만 바꾸는 자동 정렬을 함께 제공하기로 했다.

### 수정 기록 2
- 발견한 문제: 학습 화면에서 "힌트 보기" 버튼이 카드 아래에 다른 버튼과 나란히 있어, 카드에 딸린 기능이라는 느낌이 약했다.
- AI에게 전달한 요청: 학습 화면의 "힌트 보기" 버튼을 카드 안 오른쪽 위로 옮겨주세요. 앞면과 정답면 모두 같은 자리에 두고, 카드 상단 장식선과 겹치지 않게 선 아래에 배치해주세요. 문제 글자가 길어도 버튼과 겹치지 않도록 카드 위쪽 여백을 늘리고, 터치 영역은 다른 버튼처럼 높이 44px 이상으로 해주세요. 힌트 내용은 지금처럼 카드 안 문제 아래에 표시해주세요.
- 수정 후 테스트 결과: 의도한 대로 작동했다. 힌트 보기 버튼이 카드 안 오른쪽 위에 표시되고, 카드 아래에는 정답 보기, 맞춤, 틀림 버튼이 남았다.
- 수정 이유: 힌트는 현재 카드를 위한 기능이므로 카드 안에 두는 것이 자연스럽다. 카드 아래에는 정답 보기, 맞춤, 틀림만 남겨 판정 흐름이 더 단순해진다.

### 수정 기록 3
- 발견한 문제: 카드를 삭제한 직후 나타나는 "삭제 취소" 버튼이 편집 화면의 카드 목록 영역 안에 있어서 눈에 잘 띄지 않았다.
- AI에게 전달한 요청: 카드를 삭제하면 화면 하단 가운데에 "카드를 삭제했습니다" 팝업이 뜨고, "삭제 취소"와 "닫기" 버튼이 보이게 해주세요. 5초가 지나면 자동으로 닫히고, 팝업이 떠 있어도 뒤 화면을 계속 조작할 수 있게 해주세요. 연속으로 삭제하면 팝업은 하나만 유지하고 5초를 다시 세며, 취소할 수 있는 것은 직전 삭제 1건뿐이게 해주세요. 다른 안내 문구와 겹치지 않게 하고, 360px 화면에서도 가로로 넘치지 않게 해주세요.
- 수정 후 테스트 결과: 의도한 대로 작동했다. 삭제하면 화면 하단에 팝업이 표시되고, 삭제 취소로 카드가 복원되며, 닫기를 누르거나 5초가 지나면 팝업이 사라졌다.
- 수정 이유: 실수로 삭제했을 때 바로 알아차리고 되돌릴 수 있어야 한다. 화면 하단 팝업은 스크롤 위치와 관계없이 눈에 띄고, 확인창 없이 빠르게 삭제하는 흐름도 유지한다.

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 동료 평가자에게 CSV 파일을 불러온 뒤 틀린 카드 집중 학습을 한 회차 진행해 달라고 요청했다.
- 사용자의 행동과 질문: 참여자는 학습 중에 힌트를 열었다가 다시 닫으려는 행동을 했지만, 한 번 연 힌트는 닫히지 않았다. 그러자 "힌트 보기 취소는 불가능한가요?"라고 물었다. 이어서 맞춤과 틀림을 잘못 누르고는 이전 상태로 되돌리려고 했지만 방법이 없었고, "카드를 잘못 눌렀는데, 되돌리기는 불가능한가요?"라고 물었다. 두 가지 모두 내가 직접 사용하면서 느낀 불편과 같았다.
- 받은 피드백:
  1. 힌트 보기 버튼을 한 번 더 누르면 힌트가 사라졌으면 좋겠다. (현재는 한 번 열면 계속 보임)
  2. 정답 보기 전 앞면에 지금 보이는 것이 영단어인지 뜻인지 표시가 있으면 좋겠다.
  3. 맞춤이나 틀림을 잘못 눌렀을 때를 대비해 이전 카드로 돌아가기 버튼이 있으면 좋겠다.
- 반영 내용과 결과:
  1. 힌트 보기 버튼을 다시 누르면 힌트가 닫히도록 수정(문구는 "힌트 보기" 유지, 단축키 H도 동일). 결과: 의도한 대로 작동했다.
  2. 앞면 문제 글자 바로 위에 "영단어" 또는 "뜻"을 표시하도록 수정(정답면의 표시와 같은 모양). 결과: 의도한 대로 작동했다.
  3. 학습 진행 화면에 "이전 카드" 버튼을 추가하고 직전 1장으로만 돌아가 판정을 취소한 뒤 다시 판정하도록 수정(Backspace 단축키 포함). 결과: 의도한 대로 작동했다.
