# 영단어 플래시카드

## 대상 사용자

- 영단어를 암기해야 하는 학습자(학생, 수험생, 시험 준비자, 직장인)
- 엑셀이나 CSV 파일로 직접 단어 목록을 만들고 관리할 수 있는 사용자
- PC 브라우저를 주로 쓰고, 스마트폰 브라우저에서도 열어 볼 수 있어야 하는 사용자

## 사용 목적

- 영단어 카드를 넘기며 암기할 수 있는 플래시카드 학습 도구를 제공합니다.
- CSV 파일로 카드 세트를 불러오고 내보내서 단어 관리를 쉽게 합니다.
- 카드별 맞춤/틀림 기록을 저장하고, 그 기록으로 전체 학습, 맞춘 카드 복습, 틀린 카드 집중 학습을 나누어 진행합니다.

## 화면 구성과 동작

### 1. 전체 구조

- 화면 상단에 탭 2개를 둡니다: "카드 세트 목록" 탭, "학습" 탭.
- 카드 세트 편집 화면은 탭이 아니라, 목록에서 진입하는 별도 화면입니다. 편집 화면에서 "목록으로" 버튼으로 돌아옵니다.
- 앱을 처음 열었을 때는 "카드 세트 목록" 탭이 보입니다.
- 학습 중 다른 탭으로 이동하면 진행 중인 학습은 중단되고 이어하기는 지원하지 않습니다. 이미 누른 맞춤/틀림 기록은 저장된 상태로 유지됩니다.

### 2. 카드 세트 목록 탭

- 상단에 "새 세트 만들기", "CSV 불러오기" 버튼을 둡니다.
- 세트가 하나도 없으면 "카드 세트가 없습니다. 새로 만들거나 CSV 파일을 불러오세요."라는 안내 문구를 보여 줍니다.
- 세트 한 줄(카드)에는 다음을 표시합니다.
  - 세트 이름
  - 전체 카드 수, 맞춤 수, 틀림 수, 미학습 수
  - 버튼: "학습하기", "편집", "CSV 내보내기", "기록 초기화", "삭제"
- "새 세트 만들기": 세트 이름을 입력받는 입력창이 나오고, 확인하면 빈 세트가 만들어진 뒤 바로 편집 화면으로 이동합니다. 이름이 비어 있으면 만들어지지 않고 안내 문구를 보여 줍니다.
- "학습하기": 해당 세트를 선택한 상태로 "학습" 탭으로 이동합니다.
- "편집": 해당 세트의 편집 화면으로 이동합니다.
- "기록 초기화": 확인창("이 세트의 맞춤/틀림 기록을 모두 지웁니다. 계속할까요?")을 거친 뒤 모든 카드를 "미학습"으로 되돌립니다. 카드 내용은 지워지지 않습니다.
- "삭제": 확인창("세트와 기록이 모두 삭제되며 되돌릴 수 없습니다.")을 거친 뒤 삭제합니다.

### 3. CSV 불러오기 동작

- 파일 선택창에서 .csv 파일을 고릅니다. 확장자는 .csv, .txt를 허용합니다.
- 세트 이름은 파일 이름에서 확장자를 뗀 값으로 합니다. 같은 이름의 세트가 이미 있으면 "이름 (2)", "이름 (3)"처럼 번호를 붙여 새 세트로 만듭니다. 기존 세트를 덮어쓰거나 병합하지 않습니다.
- 파일 형식은 아래 "필요한 자료"의 CSV 규격을 따릅니다.
- 불러오기 전에 미리보기(총 몇 개 카드, 몇 줄을 건너뜀)를 보여 주고, 사용자가 "불러오기"를 눌러야 저장합니다.
- 건너뛰는 줄(단어 또는 뜻이 비어 있는 줄)은 개수와 줄 번호를 알려 줍니다. 최대 10개 줄 번호까지 표시하고 나머지는 "외 N줄"로 표기합니다.
- 같은 세트 안에서 영단어가 중복되는 줄은 삭제하지 않고 모두 가져옵니다. 대신 미리보기에 "중복 단어 N개"를 알려 줍니다. 대소문자만 다른 단어는 같은 단어로 보고 중복으로 집계합니다.
- 파일 형식이 잘못되었거나 유효한 카드가 0개이면 저장하지 않고 이유를 안내합니다.

### 4. CSV 내보내기 동작

- "CSV 내보내기"를 누르면 브라우저 다운로드로 파일이 저장됩니다. 파일 이름은 "세트이름.csv"입니다. 파일 이름에 쓸 수 없는 문자(\ / : * ? " < > |)는 밑줄(_)로 바꿉니다.
- 내보내기 파일에는 맞춤/틀림 상태 열을 항상 포함합니다. 상태 열을 빼는 옵션은 두지 않습니다.
- 내보낸 파일을 다시 불러오면 카드 내용과 맞춤/틀림 상태가 그대로 복원됩니다.

### 5. 카드 세트 편집 화면

- 상단에 세트 이름(수정 가능한 입력창)과 "목록으로" 버튼을 둡니다.
- 카드 목록은 표 형태입니다. 열은 번호, 영단어, 뜻, 힌트, 상태(읽기 전용), 삭제 버튼입니다.
- 표 위에 "카드 추가" 영역(영단어, 뜻, 힌트 입력창과 "추가" 버튼)을 둡니다. 영단어와 뜻은 필수, 힌트는 선택입니다.
- 표의 각 칸은 직접 클릭해서 수정합니다. 수정 내용은 입력창 밖을 누르거나 Enter를 누르면 저장됩니다. 영단어나 뜻을 비워 두고 저장하려 하면 저장되지 않고 원래 값으로 되돌아가며 안내 문구를 보여 줍니다.
- 카드 내용(영단어, 뜻)을 수정하면 그 카드의 맞춤/틀림 상태는 "미학습"으로 초기화됩니다. 힌트만 수정할 때는 상태가 유지됩니다. 상태가 초기화되는 수정은 별도 확인창 없이 저장하고, 화면에 "상태가 초기화되었습니다"라고 짧게 알립니다.
- 카드 삭제는 확인창 없이 바로 삭제하되, 삭제 직후 "삭제 취소" 버튼을 5초간 보여 줍니다. 취소할 수 있는 것은 직전 삭제 1건뿐입니다.
- 편집 화면에서 카드를 위아래로 끌어서 순서를 바꾸는 기능은 없습니다. 순서는 추가한 순서입니다.
- 카드 수 상한은 세트당 2,000개입니다. 이를 넘기는 CSV는 앞의 2,000개만 가져오고 그 사실을 안내합니다.

### 6. 학습 탭

#### 6-1. 학습 시작 화면

- 세트 선택 목록(드롭다운)을 둡니다. 목록에서 "학습하기"로 들어왔다면 해당 세트가 미리 선택되어 있습니다.
- 학습 모드 3가지를 선택 버튼으로 둡니다. 각 모드 옆에 해당 카드 수를 표시합니다.
  - 전체 학습: 세트의 모든 카드(미학습, 맞춤, 틀림 모두)
  - 맞춘 카드 복습: 현재 상태가 "맞춤"인 카드만
  - 틀린 카드 집중 학습: 현재 상태가 "틀림"인 카드만
- 카드 순서 옵션: "섞기"(기본값)와 "원래 순서" 중 선택합니다.
- 카드 방향 옵션: "영단어 → 뜻"(기본값)과 "뜻 → 영단어" 중 선택합니다.
- 선택한 모드의 카드 수가 0이면 "시작" 버튼을 비활성화하고 "해당하는 카드가 없습니다"라고 안내합니다.
- "시작" 버튼을 누르면 학습이 시작됩니다.

#### 6-2. 학습 진행 화면

- 화면 중앙에 카드 1장을 크게 보여 줍니다. 카드 앞면에는 선택한 방향에 따른 문제(영단어 또는 뜻)만 표시합니다.
- 상단에 진행 상황("3 / 20")과 진행 막대, "학습 종료" 버튼을 둡니다.
- 카드 아래에 버튼 4개가 항상 보입니다: "힌트 보기", "정답 보기", "맞춤", "틀림".
- "힌트 보기": 카드에 힌트 문구를 표시합니다. 힌트가 비어 있는 카드는 "등록된 힌트가 없습니다"라고 표시합니다. 힌트를 한 번 열면 그 카드에서는 계속 보입니다. 힌트를 본 사실은 기록하지 않습니다.
- "정답 보기": 카드 뒷면(답)을 표시합니다. 뒷면에는 영단어와 뜻을 모두 보여 줍니다.
- "맞춤", "틀림" 버튼은 "정답 보기"를 누르기 전에는 비활성화 상태로 보이고, 누른 뒤에 활성화됩니다. 정답을 보지 않고 자기 평가를 하는 것을 막기 위해서입니다.
- "맞춤": 그 카드 상태를 "맞춤"으로 저장하고 시각 피드백을 보여 준 뒤 다음 카드로 넘어갑니다.
- "틀림": 그 카드 상태를 "틀림"으로 저장하고 시각 피드백을 보여 준 뒤 다음 카드로 넘어갑니다.
- 맞춤/틀림은 사용자가 정답을 보고 스스로 판정하는 방식입니다. 영단어를 직접 입력해 앱이 자동 채점하는 방식은 이번 범위에 포함하지 않습니다.
- 기록 저장 규칙은 다음과 같습니다.
  - 카드마다 가장 최근 결과 하나만 저장합니다("미학습", "맞춤", "틀림" 중 하나). 맞춘 횟수, 틀린 횟수, 날짜는 저장하지 않습니다.
  - 틀린 카드 집중 학습에서 "맞춤"을 누르면 그 카드는 "맞춤"으로 바뀌어 다음 번 틀린 카드 집중 학습 대상에서 빠집니다.
  - 맞춘 카드 복습에서 "틀림"을 누르면 그 카드는 "틀림"으로 바뀝니다.
  - 학습 중간에 "학습 종료"를 눌러도, 이미 누른 맞춤/틀림은 저장된 상태로 남습니다.
- 학습 대상 카드 목록은 학습을 시작하는 시점에 고정됩니다. 학습 도중 틀린 카드를 같은 회차에서 다시 보여 주지 않으며, 같은 회차 안에서 카드는 한 번씩만 나옵니다.
- 이전 카드로 돌아가는 기능은 없습니다.
- 키보드 단축키는 데스크톱에서만 제공합니다: 스페이스바는 정답 보기, 왼쪽 방향키는 틀림, 오른쪽 방향키는 맞춤, H는 힌트 보기. 맞춤/틀림 단축키는 정답을 본 뒤에만 동작합니다.

#### 6-3. 학습 결과 화면

- 학습 대상 카드를 모두 마치면 결과 화면을 보여 줍니다: 이번 회차에서 맞춘 카드 수, 틀린 카드 수, 정답률(맞춤 수 / 전체 수, 소수점 첫째 자리 반올림 백분율).
- 버튼: "틀린 카드만 다시 학습"(이번 회차에서 틀린 카드로 즉시 새 회차 시작), "같은 설정으로 다시 시작", "목록으로 돌아가기".
- "학습 종료" 버튼으로 중간에 끝낸 경우에는 결과 화면 없이 학습 시작 화면으로 돌아갑니다.

### 7. 시각 피드백

- 맞춤 버튼: 카드 테두리가 초록색으로 바뀌고 체크 표시가 카드 위에 커졌다가 사라지는 애니메이션을 약 0.6초 보여 준 뒤 다음 카드로 넘어갑니다.
- 틀림 버튼: 카드 테두리가 빨간색으로 바뀌고 카드가 좌우로 짧게 흔들리는 애니메이션을 약 0.6초 보여 준 뒤 다음 카드로 넘어갑니다.
- 피드백이 진행되는 동안(0.6초) 버튼 중복 클릭은 무시합니다.
- 색만으로 구분하지 않도록 체크 표시(맞춤)와 X 표시(틀림)를 함께 보여 줍니다.
- 브라우저/운영체제에서 "동작 줄이기"(prefers-reduced-motion)가 켜져 있으면 움직임 없이 색과 표시만 0.3초간 보여 줍니다.
- 효과음은 넣지 않습니다.

## 필요한 자료

### CSV 파일 규격

- 인코딩: UTF-8을 기본으로 합니다. 불러올 때 파일 맨 앞의 BOM(UTF-8 서명)은 자동으로 제거합니다. 내보낼 때는 엑셀에서 한글이 깨지지 않도록 BOM을 붙입니다. UTF-8이 아닌 인코딩(예: EUC-KR/CP949)은 지원하지 않으며, 깨져서 읽히면 "UTF-8 형식의 파일이 필요합니다"라고 안내합니다.
- 구분자: 쉼표(,)만 지원합니다. 세미콜론, 탭은 지원하지 않습니다.
- 첫 줄은 헤더입니다. 헤더 이름은 다음과 같습니다.
  - word (영단어, 필수)
  - meaning (뜻, 필수)
  - hint (힌트, 선택)
  - status (상태, 선택): 허용값은 "unseen", "correct", "wrong" 세 가지입니다. 비어 있거나 다른 값이면 "unseen"으로 처리합니다.
- 열 순서는 헤더 이름으로 인식하므로 순서가 바뀌어도 읽을 수 있습니다. 대소문자는 구분하지 않고, 앞뒤 공백은 제거합니다.
- 헤더에 word 또는 meaning 열이 없으면 불러오기를 중단하고 이유를 안내합니다.
- 알 수 없는 열은 무시하고, 무시한 열 이름을 미리보기에서 알려 줍니다.
- 큰따옴표로 감싼 칸, 칸 안의 쉼표, 칸 안의 줄바꿈, 큰따옴표 이스케이프("")는 표준 CSV 규칙대로 처리합니다. 내보낼 때도 같은 규칙으로 출력합니다.
- 엑셀에서 열 때 수식으로 오해되지 않도록, 내보낼 때 칸이 =, +, -, @로 시작하면 앞에 작은따옴표(')를 붙여 저장합니다. 불러올 때는 이 작은따옴표를 제거하지 않습니다(데이터 그대로 읽습니다).
- 한 칸의 글자 수 상한은 영단어 100자, 뜻 300자, 힌트 300자입니다. 초과하는 값은 상한까지만 잘라 가져오고 건수를 알려 줍니다.
- 줄바꿈 문자는 CRLF, LF 모두 읽을 수 있고, 내보낼 때는 CRLF를 사용합니다.

CSV 예시:

```
word,meaning,hint,status
apple,사과,과일,correct
benevolent,자애로운,b로 시작,wrong
```

### 앱에 포함할 기본 자료

- 앱 첫 실행 시 예시 세트는 자동으로 만들지 않습니다. 대신 세트가 없는 빈 목록 화면에 샘플 CSV 다운로드 버튼("샘플 CSV 받기")을 둡니다. 샘플은 위 예시 형식으로 단어 5개를 담습니다.
- 모든 화면 문구는 한국어입니다. 외부 글꼴, 이미지, 라이브러리, 아이콘 파일 등 외부 자료는 사용하지 않습니다. 아이콘이 필요하면 텍스트 기호 또는 HTML 안에 포함된 SVG로 만듭니다.

### 저장 방식

- 브라우저의 localStorage에 저장합니다. 키 이름은 "vocab-flashcards-v1" 하나이며, 모든 세트를 하나의 JSON 객체로 저장합니다.
- 데이터 구조는 다음과 같습니다.
  - 세트: 고유 ID, 이름, 생성 시각, 카드 배열
  - 카드: 고유 ID, 영단어, 뜻, 힌트, 상태("unseen", "correct", "wrong")
- 저장은 카드/세트가 바뀔 때마다 자동으로 합니다. 별도의 "저장" 버튼은 없습니다.
- 앱을 다시 열면 저장된 데이터를 불러옵니다. 저장된 데이터가 손상되어 읽을 수 없을 때는 데이터를 지우지 않고 "저장된 데이터를 읽을 수 없습니다" 안내와 함께 빈 상태로 시작합니다. 손상된 데이터는 다른 키("vocab-flashcards-v1-broken")에 백업해 둡니다.
- 저장 용량 초과, 저장 차단(예: 시크릿 모드) 시에는 화면 상단에 "저장에 실패했습니다. CSV로 내보내 백업하세요."라는 경고 띠를 표시합니다.

### 화면 디자인

- 색상은 밝은 배경 한 가지 테마만 사용합니다(다크 모드 없음).
- 글자 크기는 카드 문제 글자를 가장 크게(데스크톱 기준 약 32px 이상), 본문은 16px 이상으로 합니다.
- 반응형: 가로 폭 360px 이상 화면에서 가로 스크롤 없이 쓸 수 있어야 합니다. 편집 화면의 표는 좁은 화면에서는 카드 1장씩 세로로 쌓이는 형태로 바뀝니다.

## 완료 기준

- 다른 파일, 서버, 로그인, 인터넷 연결 없이 HTML 파일 하나를 브라우저에서 열면 동작합니다.
- 새 세트를 만들고 카드를 추가, 수정, 삭제할 수 있으며, 브라우저를 닫았다가 다시 열어도 세트와 카드가 그대로 남아 있습니다.
- 위 CSV 규격에 맞는 파일을 불러오면 미리보기가 나오고, 확인하면 새 세트가 만들어지며, 카드 수가 파일의 유효한 줄 수와 같습니다.
- 헤더에 word 또는 meaning이 없는 파일, 유효한 줄이 0개인 파일, 빈 파일을 불러오면 저장되지 않고 이유가 안내됩니다.
- 쉼표와 줄바꿈과 큰따옴표가 들어 있는 칸이 포함된 CSV를 불러온 뒤 다시 내보내도 내용이 변하지 않습니다.
- CSV 내보내기로 받은 파일을 엑셀에서 열면 한글이 깨지지 않고, 그 파일을 다시 불러오면 카드 내용과 맞춤/틀림 상태가 같게 복원됩니다.
- 학습 화면에서 힌트 보기, 정답 보기, 맞춤, 틀림 버튼 4개가 항상 보이고, 맞춤/틀림은 정답을 보기 전에는 눌러지지 않습니다.
- 맞춤을 누르면 해당 카드 상태가 "맞춤"으로, 틀림을 누르면 "틀림"으로 저장되고, 새로고침 후에도 유지됩니다.
- 전체 학습은 세트의 모든 카드를, 맞춘 카드 복습은 "맞춤" 카드만, 틀린 카드 집중 학습은 "틀림" 카드만 보여 줍니다. 각 모드 옆에 표시된 카드 수와 실제 출제 카드 수가 같습니다.
- 해당 모드의 카드가 0장이면 학습을 시작할 수 없고 안내 문구가 나옵니다.
- 틀린 카드 집중 학습에서 맞춤을 누른 카드는 다음 틀린 카드 집중 학습에서 나오지 않습니다.
- 카드의 영단어나 뜻을 수정하면 그 카드의 상태가 "미학습"이 되고, 힌트만 수정하면 상태가 유지됩니다.
- 맞춤/틀림을 누르면 각각 다른 시각 피드백(초록 체크 / 빨간 X와 흔들림)이 나오고, 피드백 도중 연속 클릭해도 카드가 건너뛰어지지 않습니다.
- 학습 결과 화면의 맞춤 수, 틀림 수, 정답률이 실제로 누른 횟수와 일치합니다.
- "기록 초기화"를 하면 모든 카드가 "미학습"이 되고 카드 내용은 남아 있으며, 삭제 시에는 확인창이 먼저 나옵니다.
- 세트 2개 이상을 만들어도 각 세트의 기록이 서로 섞이지 않습니다.
- 화면 가로 폭 360px에서 가로 스크롤이 생기지 않습니다.
- 브라우저 개발자 도구 콘솔에 오류가 나타나지 않습니다.

## 한계 및 비목표

1. 데이터는 사용하는 브라우저 안에만 저장됩니다. 다른 기기, 다른 브라우저, 다른 프로필과 자동으로 동기화되지 않습니다. 브라우저의 사이트 데이터를 지우면 기록이 사라질 수 있으므로 CSV 내보내기로 정기 백업이 필요합니다. 브라우저에 따라 파일을 직접 열었을 때(file:// 주소) 저장소를 파일 경로마다 따로 취급하거나 시크릿 모드에서 저장이 안 될 수 있습니다. 이 동작은 브라우저와 버전마다 다를 수 있어, 사용하려는 브라우저에서 직접 확인이 필요합니다. 이 부분은 이 기획 단계에서 확인할 수 없습니다.
2. 앱이 원본 CSV 파일을 직접 덮어쓰거나 특정 폴더에 자동 저장하는 것은 하지 않습니다. 내보내기는 항상 브라우저 다운로드이며, 저장 위치 선택은 브라우저 설정에 따릅니다. (파일 직접 저장 기능은 일부 브라우저에만 있어 지원 범위에서 제외합니다.)
3. 서버, 계정, 클라우드 동기화, 여러 사용자 간 공유는 만들지 않습니다.
4. 영단어의 뜻, 발음, 예문을 외부 사전에서 자동으로 가져오는 기능은 만들지 않습니다. 인터넷 연결 없이 HTML 파일 하나로 동작해야 한다는 조건과 충돌하기 때문입니다.
5. 맞춤/틀림은 사용자가 정답을 보고 스스로 누르는 자기 평가입니다. 앱이 정답 여부를 자동으로 검증하지 않습니다.
6. 카드당 최근 결과 하나만 저장합니다. 맞춘 횟수, 틀린 횟수, 학습 날짜 등의 이력은 저장하지 않습니다.
7. CSV는 UTF-8, 쉼표 구분만 지원합니다. 엑셀 파일(.xlsx)을 직접 불러오는 기능은 없습니다. 엑셀에서 "CSV UTF-8" 형식으로 저장한 파일을 사용해야 합니다. 앱이 파일의 인코딩을 완벽하게 자동 판별하는 것은 어렵기 때문에, UTF-8이 아닌 파일은 깨져서 읽힐 수 있습니다.
8. 두 파일을 하나의 세트로 합치거나, 기존 세트에 CSV를 덧붙이는 병합 기능은 이번 범위에서 제외합니다. 필요하면 CSV를 엑셀에서 합친 뒤 새 세트로 불러옵니다.
9. 학습 중 이전 카드로 돌아가기, 학습 도중 이어하기, 같은 회차 안에서 틀린 카드 재출제는 이번 범위에서 제외합니다.
10. 세트당 카드 수는 2,000개, 한 칸의 글자 수는 "필요한 자료"에 적은 상한으로 제한합니다. 브라우저 저장 용량(일반적으로 약 5MB 안팎이지만 브라우저마다 다름)을 넘기면 저장에 실패할 수 있습니다.
11. 지원 브라우저는 최신 버전의 Chrome과 Edge를 기준으로 합니다. Safari, Firefox와 스마트폰 브라우저에서도 동작하도록 만들지만, 실제 동작은 각 환경에서 직접 확인해야 합니다. 이 기획 단계에서는 확인할 수 없습니다.
12. 접근성(스크린 리더 지원 등)은 기본적인 키보드 조작과 색에만 의존하지 않는 표시 수준으로 제한합니다. 전체 접근성 기준 준수는 목표가 아닙니다.
13. 카드 편집 화면에서 여러 사람이 동시에 같은 데이터를 수정하는 경우(같은 브라우저의 탭 2개 이상)는 고려하지 않습니다. 마지막에 저장한 내용이 남습니다.

## 검증 방법

- CSV 가져오기: 카드 5개, 특수 문자(쉼표, 큰따옴표, 줄바꿈)가 포함된 칸 2개, 단어가 빈 줄 1개가 들어 있는 테스트 CSV를 만들어 불러옵니다. 카드 수가 5개인지, 특수 문자 칸이 원본과 글자 단위로 같은지, 건너뛴 줄 수가 1로 안내되는지 파일 내용과 직접 대조합니다.
- CSV 왕복 확인: 세트 하나를 내보낸 뒤 그 파일을 다시 불러오고, 원본 세트와 새 세트의 카드 수, 각 카드의 단어, 뜻, 힌트, 상태가 모두 같은지 하나씩 비교합니다.
- 엑셀 호환 확인: 내보낸 CSV를 엑셀과 메모장에서 각각 열어 한글이 깨지지 않는지 확인합니다. 수식 문자로 시작하는 칸(예: =test)이 수식으로 실행되지 않는지 확인합니다.
- 상태 저장 확인: 카드 10개 중 맞춤 4개, 틀림 3개를 눌러 보고 나머지를 미학습으로 둔 뒤, 목록 탭의 맞춤, 틀림, 미학습 수가 4, 3, 3인지 손으로 센 값과 비교합니다. 새로고침한 뒤에도 같은 수인지 확인합니다.
- 모드 구분 확인: 위 상태에서 전체 학습은 10장, 맞춘 카드 복습은 4장, 틀린 카드 집중 학습은 3장이 나오는지, 나온 카드의 단어가 직접 기록한 맞춤/틀림 단어와 일치하는지 대조합니다.
- 상태 전환 확인: 틀린 카드 집중 학습에서 카드 1장에 맞춤을 누른 뒤, 목록 탭 수치가 맞춤 5, 틀림 2로 바뀌었는지 확인합니다.
- 정답률 확인: 한 회차에서 맞춤 3회, 틀림 1회를 누르고 결과 화면이 맞춤 3, 틀림 1, 정답률 75.0%로 표시되는지 직접 계산한 값과 비교합니다.
- 편집 규칙 확인: 영단어를 수정하면 상태가 미학습이 되는지, 힌트만 수정하면 상태가 유지되는지 확인합니다. 단어를 빈칸으로 저장하려 할 때 거부되는지 확인합니다.
- 버튼 동작 확인: 정답 보기를 누르기 전에는 맞춤/틀림이 눌러지지 않는지, 맞춤/틀림을 빠르게 연속으로 눌러도 카드가 한 장씩만 넘어가는지 확인합니다.
- 오류 상황 확인: 빈 파일, 헤더가 잘못된 파일, 이미지 파일의 확장자만 .csv로 바꾼 파일을 불러올 때 오류 안내가 나오고 기존 데이터가 그대로인지 확인합니다.
- 화면 확인: 브라우저 창 폭을 360px로 줄여 가로 스크롤이 생기지 않는지, 개발자 도구 콘솔에 오류가 없는지 확인합니다. 최신 Chrome과 Edge에서 위 항목을 모두 수행하고, 다른 브라우저는 수행한 항목만 기록합니다.
- 독립 실행 확인: 인터넷 연결을 끊은 상태에서 HTML 파일을 더블클릭해 열었을 때 모든 기능이 동작하는지 확인합니다.
